Catatan

Viewer bersifat read-only murni: cocok untuk petugas yang hanya perlu memantau layar, tanpa risiko tidak sengaja mengubah pengaturan kamera atau menghapus data.

§1 Masuk ke Aplikasi

Berlaku untuk semua peran.

  1. Buka alamat aplikasi di browser.
  2. Masukkan Username dan Password yang diberikan admin, lalu klik Masuk.
  3. Sesi login bertahan 12 jam — setelah itu, sistem meminta login ulang otomatis.
Perhatian

Jangan bagikan akun admin ke operator harian. Buat akun terpisah dengan peran Operator atau Viewer sesuai kebutuhan tugas (lihat §8).

§2 Menambah & Mengatur Kamera

AdminOperator

Klik + Tambah kamera di halaman Live View. Field wajib hanya Nama dan Alamat IP — sisanya opsional dan bisa dilengkapi belakangan.

Cara mengisi RTSP

  • Manual — isi kolom RTSP path (contoh: /Streaming/Channels/101) beserta username/password kamera. Sistem otomatis merakit URL RTSP lengkap.
  • Probe ONVIF — simpan kamera dulu, lalu buka menu ··· pada tile → Probe ONVIF. Sistem mengambil sendiri URL stream dan mendeteksi dukungan PTZ. Tidak berlaku untuk kamera relay.

Kamera di jaringan privat (relay agent)

Untuk kamera yang IP-nya tidak bisa dijangkau langsung dari server, centang "Kamera di jaringan privat". Sistem menampilkan perintah siap-pakai:

node relay-agent.js --server=<alamat-server> --token=<token> --rtsp="rtsp://..."

Jalankan perintah ini di PC yang satu jaringan dengan kamera tersebut. Kamera relay tidak mendukung Probe ONVIF, PTZ, atau rekam manual dari server pusat.

Import banyak kamera sekaligus (CSV)

Klik Import CSV → unduh template dulu. Kolom yang dipakai: name, brand, ip, rtsp_port, onvif_port, username, password, rtsp_path, location. Baris tanpa name/ip otomatis dilewati.

§3 Live View — Pemantauan Langsung

Semua peran

Klik Live pada tile kamera untuk mulai menonton; klik lagi untuk berhenti. Tombol Nyalakan Semua / Hentikan Semua berlaku untuk seluruh kamera pada filter yang sedang aktif.

  • Gunakan pencarian dan filter Status/Fungsi untuk mempersempit daftar kamera.
  • Pilih tata letak grid (1×1 sampai 4×4, atau spotlight) sesuai kebutuhan.
  • Klik tile untuk membuka tampilan fokus lengkap dengan kontrol rekam dan motion.
Status badge

"Live" berarti gambar aktif. "Reconnecting" berarti sistem sedang mencoba menyambung ulang otomatis — normal untuk kamera di jaringan WAN dan akan pulih sendiri, tidak perlu diklik ulang.

§4 Kontrol PTZ

AdminOperator

Kontrol arah panah dan tombol stop hanya muncul pada kamera yang mendukung PTZ (ditandai otomatis lewat Probe ONVIF). Tahan tombol arah untuk menggerakkan kamera, lepas untuk berhenti. Tidak berlaku untuk kamera relay.

§5 Rekaman & Retensi

Admin Operator dapat menyalakan/mematikan rekaman manual per kamera. Semua peran dapat melihat dan mengunduh rekaman di menu Rekaman.

  • Rekaman tersimpan dalam segmen berdurasi 10 menit per file.
  • File otomatis dihapus setelah melewati masa retensi (default 14 hari, diatur admin di §9).
  • Tombol Putar membuka pemutar video di browser; Unduh menyimpan file ke perangkat.
Perhatian

Masa retensi berlaku global untuk semua kamera. Kalau ada rekaman penting yang harus disimpan lebih lama, unduh filenya sebelum masa retensi habis.

§6 Deteksi Gerakan (Motion Detection)

AdminOperator

Aktifkan lewat menu ··· pada tile → Hidupkan Motion, atau saat edit kamera. Sensitivitas diatur 0.01–0.50 (default 0.04) — makin kecil angkanya, makin sensitif.

  • Setiap gerakan dicatat di Log Peristiwa, dengan jeda minimal 10 detik antar-pencatatan.
  • Kalau "Rekam otomatis saat motion" juga aktif, sistem langsung merekam saat gerakan terdeteksi — rekaman ini tidak berhenti otomatis, harus dimatikan manual.
  • Motion detection butuh RTSP URL yang sudah terisi (lewat probe ONVIF atau input manual).

§7 Lokasi & Peta

AdminOperator

Lokasi mengelompokkan kamera di sidebar dan filter Live View, serta menandai posisi di peta (menu Peta Lokasi). Tambah/edit lewat form, atau klik langsung di peta.

Otomatis

Kamera baru tanpa lokasi manual akan ditebak lokasinya dari nama, dan khusus IP publik — diperkirakan koordinat kotanya dari IP tersebut. Akurasinya level kota saja, periksa dan sesuaikan pin secara manual bila perlu.

§8 Manajemen User

Admin

Menu ini hanya tampil untuk admin. Tambahkan satu akun per petugas (jangan berbagi akun), dan pilih peran sesuai tanggung jawabnya — lihat tabel akses di §0.

§10 Notifikasi Kamera Offline

Admin

Sistem mengecek keterjangkauan tiap kamera secara berkala, terpisah dari live view. Dengan pengaturan default — cek tiap 5 menit, dianggap offline setelah 2 kali gagal berturut-turut — kamera baru ditandai offline setelah kira-kira 10 menit tidak terjangkau.

Email notifikasi hanya terkirim kalau semua kolom di Pengaturan → Notifikasi Email terisi: toggle aktif, SMTP host, username, password, dan email tujuan. Gunakan tombol Kirim Email Test untuk memastikan konfigurasi sudah benar.

§11 Troubleshooting Umum

Gejala yang paling sering ditemui di lapangan, penyebab, dan cara mengatasinya.

Live stream terus-menerus "Reconnecting", gambar tidak pernah muncul
PenyebabKredensial kamera salah, RTSP path salah, atau kamera mati/tidak terjangkau.
SolusiCek Log Peristiwa untuk kamera itu — 401 Unauthorized berarti password salah (perbaiki di Edit Kamera), timeout berarti masalah jaringan/kamera mati. Sistem terus mencoba sambung ulang otomatis — tidak perlu menekan Live berulang-ulang.
Menyalakan satu kamera baru membuat kamera lain yang stabil ikut "Reconnecting"
PenyebabTerlalu banyak live stream memakai encoder hardware (QSV) bersamaan. Sistem sudah membatasi maksimal 3 sesi hardware sekaligus; kamera berikutnya otomatis pakai encoder software.
SolusiBiasanya pulih sendiri dalam beberapa detik. Kalau sering terjadi, gunakan Nyalakan Semua (menyalakan bertahap) daripada mengeklik banyak kamera dengan cepat, atau pakai mode encoder "Software saja" di §9.
Gambar tampil, tapi ada tulisan besar "NO VIDEO" di dalam frame
PenyebabBukan masalah aplikasi — tulisan itu dikirim langsung oleh NVR, artinya channel sudah dikonfigurasi tapi tidak ada kamera fisik yang tersambung.
SolusiPeriksa kabel/koneksi kamera fisik ke channel NVR di lokasi. Tidak ada yang perlu diubah di aplikasi.
Gambar sempat muncul lalu tiba-tiba blur/pecah sesaat
PenyebabPaket data sempat hilang/rusak di jalur jaringan (umum untuk kamera lewat internet publik/WAN) — bukan kerusakan kamera.
SolusiSistem otomatis membuang frame rusak dan melanjutkan streaming; biasanya pulih sendiri tanpa tindakan apa pun.
Kamera berpindah lokasi otomatis ke pin yang salah di peta
PenyebabPerkiraan lokasi otomatis berbasis IP publik hanya akurat sampai level kota.
SolusiPerbaiki manual lewat drag-pin di Peta Lokasi atau edit koordinat lokasi.

§12 Praktik Baik

  • Jangan bagikan satu akun ke banyak petugas — buat akun terpisah per orang agar Log Peristiwa tetap jelas siapa melakukan apa.
  • Cek Log Peristiwa berkala, bukan hanya saat ada masalah — event camera_offline dan recording_error yang menumpuk adalah tanda dini gangguan.
  • Unduh rekaman penting sebelum masa retensi habis; sistem menghapusnya otomatis tanpa pemberitahuan tambahan.
  • Saat menambah banyak kamera sekaligus, gunakan Import CSV alih-alih input satu-satu.
  • Setelah mengganti password kamera fisik, segera perbarui juga di Edit Kamera — kalau tidak, live view akan terus gagal dengan 401 Unauthorized.
